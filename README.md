# امتیازدهی بازی واشنگتن

وب‌اپلیکیشن ساده و موبایل‌فرندلی برای ثبت امتیاز بازی کارتی واشنگتن.

## نحوه اجرا روی گوشی (بدون نیاز به سرور شخصی)

### روش پیشنهادی: Streamlit Community Cloud (رایگان)

1. یک حساب GitHub بساز (اگر نداری).
2. یک ریپازیتوری جدید بساز و فایل‌های این پوشه را آپلود کن.
3. برو به [share.streamlit.io](https://share.streamlit.io)
4. با حساب GitHub وارد شو و ریپازیتوری را انتخاب کن.
5. فایل `app.py` را به عنوان Main file مشخص کن.
6. Deploy کن.

بعد از چند دقیقه یک لینک عمومی می‌گیری که می‌توانی روی گوشی باز کنی و حتی به Home Screen اضافه کنی.

## اجرای محلی (اختیاری)

```bash
pip install -r requirements.txt
streamlit run app.py
```
